# Rugless Buckle - Devnet assets

Public metadata and artwork for a Rugless Pump.fun Devnet integration test. This token has no monetary value and is not the production $RUGLESS token.

- `m.json`: name, symbol, description and HTTPS image reference.

GitHub HTTPS hosting is used for this development test, not an immutable production storage guarantee. Production storage/pinning policy remains to be selected. Do not replace these files after launching the associated token.
